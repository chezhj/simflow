Safe to extend base.html: axes renders this through `render(request, template, context, status=AXES_HTTP_RESPONSE_CODE)`, so the request is passed and the context processors run. Contrast 500.html, which gets neither. axes supplies `failure_limit`, `username`, and — only when AXES_COOLOFF_TIME is set — `cooloff_time` (an ISO 8601 duration string) and `cooloff_timedelta`. We set the cooloff, so both are present; `natural_duration` turns the timedelta into words rather than "0:30:00", and reads from the same setting the lockout itself uses, so the two cannot drift apart. `username` is deliberately not echoed. It is whatever was typed into the form, and reflecting attacker-chosen text into a page is a habit worth not having even where autoescaping makes it safe.
